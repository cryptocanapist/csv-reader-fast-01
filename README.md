A fast drop-in for csv-reader 1.0.0: the same answers on every broken CSV, but about 2.5x faster on the practice set. Plain records take a native indexOf/split fast path, while quoted, multiline and broken rows take an exact slow path that reproduces csv-reader's stray_cr, quote_junk, unterminated_quote, short_row and long_row errors.

## Run it

```sh
MAKEFUN_INPUT_DIR=./input MAKEFUN_OUTPUT_DIR=./output node main.ts
```
